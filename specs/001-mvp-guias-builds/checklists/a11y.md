# Checklist de revisión manual de accesibilidad: MVP de guías y builds (T-043)

**Propósito**: Revisión manual con teclado, NVDA y contraste que complementa las
puertas automáticas de T-040/T-041. Es el criterio de cierre de T-043.
**Creada**: 2026-11-12
**Feature**: [spec.md](../spec.md) · [tasks.md](../tasks.md) (T-043)
**Alcance**: WCAG 2.2 niveles A y AA, en las configuraciones regionales `en`
(raíz) y `es` (`/es`).
**Estado**: lista para ejecutar; **sin firmar**. Solo el revisor humano marca
casillas y firma.

## Cómo usar esta checklist

1. Registra el entorno en la sección [Firma](#firma) antes de empezar.
2. Ejecuta cada ítem en el orden de la página. Marca `[x]` solo si el resultado
   observado coincide con el esperado; si no, deja `[ ]` y anota un hallazgo en
   [Hallazgos](#hallazgos) con su ID.
3. Repite las secciones de rutas en `en` y en `es`, salvo que el ítem diga lo
   contrario. Cada ítem indica el criterio WCAG que verifica.

### Entorno a registrar

- Windows (versión), navegador y versión (Chrome o Firefox actuales).
- Versión de NVDA y modos usados: exploración y foco (`Insert+Espacio` alterna).
- Zoom del navegador y ancho de ventana probados (al menos 1280 px y 320 px CSS,
  equivalente a zoom 400 % sobre 1280 px).
- Commit revisado (`git rev-parse --short HEAD`).

### Levantar el artefacto

Se revisa el **artefacto construido**, servido con las mismas cabeceras (CSP)
que usan los e2e, no `ng serve`:

```powershell
pnpm build
node --import tsx scripts/serve-artifact.mts dist/grim-dawn-builds/browser 4300
```

Abre `http://localhost:4300/` (inglés) y `http://localhost:4300/es/` (español).
El puerto es libre; `playwright.config.ts` lanza el mismo script.

### Qué cubren las pruebas automáticas y qué solo cubre esta revisión

| Puerta                                       | Cubre                                                                                                                                                 | No cubre                                                                                                                                                                           |
