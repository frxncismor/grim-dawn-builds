This page summarizes code ownership, content attribution, asset use, content takedown and privacy for the features available today.

Ownership and rights

The code of this project is published without a declared license: all rights are reserved until the maintainer chooses one.

Third-party editorial content is governed by its own licenses and permissions, which are recorded in the repository's source register.

Attribution

Each guide shows its author, its sources and its review status, together with the game version it corresponds to.

A build adapted from an external source is only published when that source's license or a registered permission expressly covers the adaptation. Visible attribution is required, but it does not replace permission.

Sources and assets

No automatic scraping is performed, and no texts, images or assets from third-party guides are copied without explicit registered permission. Access controls are not bypassed either.

Official Grim Dawn assets are only used when the asset manifest records their origin, owner, license or permission and proof, with approved status. Until that entry exists, our own SVG glyphs are used.

Content takedown

Any rights holder can request the takedown of content by opening an issue in the project channel. That same channel is also used for general contact.

Open a takedown or contact issue on GitHub

Content is unpublished first and the request is resolved afterwards.

Privacy

The site has no accounts, comments or third-party analytics.

The only local storage is the optional progress of the purchase checklist, which you can clear with the "Clear progress" button in the guide or by deleting the site data in your browser.
