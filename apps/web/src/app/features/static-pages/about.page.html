About the project

Grim Dawn Builds is an independent project for browsing mastery combinations and guides with visible provenance. It is not affiliated with Crate Entertainment.

What the statuses mean

  • Verified: content reviewed under the editorial criteria and the indicated game version.
  • Unverified: some data needs review. It is not presented with the same confidence as verified content.
  • Placeholder: an informational slot without a catalogued guide. It is not a recommendation and has no power tier.

Review and attribution

Guides identify their author, sources and game version. Publication requires review and confirmed rights. An external link keeps the attribution, but it does not grant permission to copy or adapt a guide.

Tiers require an editorial assessment with a source and a date. Anything without that assessment remains unranked.

Content and assets

We do not perform automatic scraping. Third-party content requires a license or permission that covers its use. Without one, only a link with permitted metadata is kept. Icons are our own while no authorization to use official art is registered.
